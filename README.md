# طلبات الفعاليات والبرامج — مركز عيد الثقافي

## البنية
- `src/index.html` — هيكل الصفحة.
- `src/app.css` — التنسيقات.
- `src/js/01-core.js … 07-features.js` — البرمجة مقسّمة حسب الأقسام:
  الأساس والتخزين والأمان، الواجهة والتنقل، جدول المقدّمين والإتاحة، الطلبات والمعالج،
  التقارير والطباعة، الإحصاءات والإعدادات، الميزات الإضافية (التكرار، الأرشيف، السندات…).
- `index.html` + `assets/` — نسخة النشر المضغوطة (تُولَّد تلقائيًا، لا تُعدَّل يدويًا).

## البناء
```
npm i terser csso      # مرة واحدة
node tools/build.js    # يولّد index.html و assets/
```
تُعدَّل الملفات داخل `src/` فقط، ثم يُشغَّل البناء ويُرفع الناتج.
